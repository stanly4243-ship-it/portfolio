# ITCS website experiment

Self-contained Vite project. From this folder run `npm ci` and `npm run build`. From the repository root, run `npm run dev` to preview at `/itcs/`, or `npm run build` to package the full portfolio.

Printer: `/portfolio/itcs/`. Folder alternative: `/portfolio/itcs/?hero=folder`.

The first repository build restores exact binary assets from their `.base64` transport copies. Preserve those copies and the accompanying Microsoft licence when moving the project.

See `docs/asset-records.md` for asset provenance and `docs/verification.md` for validation. Forms are local previews; voice clips and live Alison integrations are unavailable.
